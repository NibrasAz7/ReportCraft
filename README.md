# ReportCraft

*(Working name — see the naming analysis in [vision.md](vision.md); to
be confirmed.)*

A free, open-source business-intelligence studio — the clean-room,
Rust-native alternative to **Microsoft Power BI** and **SAP Business
Intelligence**.

Connect to databases, warehouses, Excel files and web sources; model
relationships and measures; build interactive dashboards, charts, tables
and pixel-accurate reports — locally, offline, with everything drivable
by command or agent.

Built the [ArtCraft](https://github.com/storytold) way — the suite's
conventions, not the suite's code.

Read **[vision.md](vision.md)** for the full vision.
